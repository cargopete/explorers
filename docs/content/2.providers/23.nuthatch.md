## Address it

```ts
import { Nuthatch } from "@agntn/explorers/providers/nuthatch";

const nest = new Nuthatch({ baseUrl: "http://127.0.0.1:8288" }); // or create("nuthatch") with NUTHATCH_URL
await nest.getBalance("0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045", "base");
```

[Nuthatch](https://github.com/nuthatch-org/nuthatch) is a self-hosted indexer. A nest in address-history mode answers Etherscan's `/api` for the addresses you told it to watch. There's no public instance: `baseUrl`, or `NUTHATCH_URL`, is the nest's root, and the provider adds `/api`. No key.

Automatic selection never picks it. Ask for it with `-p nuthatch`, or `provider: "nuthatch"`, and pass the chain the nest follows.

## What it reads

| Operation       | Route                                                    |
| --------------- | -------------------------------------------------------- |
| balance         | `module=account&action=balance`                          |
| history         | `module=account&action=txlist`                           |
| token transfers | `module=account&action=tokentx`, by address              |
| one transaction | `module=proxy&action=eth_getTransactionByHash` + receipt |
| block           | `module=proxy&action=eth_getBlockByNumber`               |

No contracts, no token holdings and no gas. The nest doesn't serve `getsourcecode`, `addresstokenbalance` or a gas oracle, so those methods are absent.

## Gotchas

- A refusal is never an empty list. `NUTHATCH_UNSUPPORTED: chainid …` is an `UnsupportedChainError`, any other `NUTHATCH_UNSUPPORTED:` an `UnsupportedOperationError` with the nest's reason after a colon, and `NUTHATCH_INCOMPLETE:` an `ExplorerError` that says how far the nest got.
- History sends block bounds only when you set them. The nest refuses a range past its head, and on Optimism and Arbitrum one that starts before the traces it trusts.
- Balances and the proxy reads come from the nest's own RPC, the way Etherscan answers its `proxy` module from its nodes.
